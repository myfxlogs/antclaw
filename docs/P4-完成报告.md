# P4 存储与鉴权 - 完成报告

## 完成日期
2026-04-25

## 已交付产物

### 1. 数据库层
- `backend/db/migrations/001-006.sql` - 6 个迁移文件
  - users（Argon2id password_hash, password_version, role, totp 预留）
  - sessions（设备会话，含 revoked_at）
  - refresh_tokens（JWT refresh，含 rotated_to 复用检测）
  - password_resets（15min 有效期令牌）
  - audit_logs（append-only，hash_prev/hash_self 哈希链，触发器禁止 UPDATE/DELETE）
  - user_ai_keys（BYOK AES-GCM 加密）

- `backend/db/queries/{auth,audit,byok}.sql` - sqlc 查询定义
- `backend/sqlc.yaml` - sqlc 配置文件
- `backend/internal/adapter/storage/postgres/db/` - 生成的 Go 类型与查询实现

### 2. 鉴权核心包
- `backend/internal/auth/password.go` - Argon2id（参数可环境变量覆盖）
- `backend/internal/auth/jwt.go` - Ed25519 JWT（access 15min / refresh 30d，双 kid 轮换）
- `backend/internal/auth/middleware.go` - Connect-RPC 鉴权拦截器
- `backend/internal/auth/ratelimit.go` - 登录失败退避 + refresh 复用检测（Redis）
- `backend/internal/auth/*_test.go` - 单元测试（Argon2id 随机 salt、JWT 往返、类型校验）

### 3. 审计服务
- `backend/internal/service/audit/audit.go` - SHA256 哈希链 + 完整性校验
- 支持 `pgtype.UUID` / `pgtype.Timestamptz` 适配 sqlc 生成类型

### 4. RPC 实现
- `backend/internal/adapter/rpc/auth_handler.go` - 完整 AuthService 实现
  - Register / Login（恒定 200ms 延迟防 timing 攻击）
  - Refresh（token rotation + 复用检测）
  - Logout（单设备/全设备）
  - 预留 RequestPasswordReset / ResetPassword / VerifyEmail

### 5. Proto 修复
- 修复 `calendar.proto` / `cot.proto` / `stream.proto` 命名规范警告
- `buf lint` 通过（仅 DEFAULT 分类弃用警告，非错误）
