## 2. 单测要求（Unit）

### 2.1 覆盖率
- 每个新增 Service / 算法包：**行覆盖 ≥ 80%**，分支覆盖 ≥ 70%。
- 算子库（indicators / calc / normalize）：行覆盖 ≥ 95%。

### 2.2 黄金对比

对于 EMA / RSI / ADX / ATR / Sharpe / MaxDD 等**有标准定义**的指标，必须有"黄金对比"单测：

```go
func TestEMA20_AgainstPandasGolden(t *testing.T) {
    // golden_data.csv 由 pandas 生成，commit 到 testdata/
    bars := loadCSV("testdata/eurusd_2024.csv")
    expected := loadCSV("testdata/eurusd_ema20.csv")
    actual := EMA(bars, 20)
    for i, exp := range expected {
        require.InDelta(t, exp, actual[i], 1e-6, "row %d", i)
    }
}
```

### 2.3 边界用例

每个 Service 方法必须覆盖：
- 空输入
- 数据不足（DATA_INSUFFICIENT 路径）
- 极端值（NaN, Inf, 负数）
- 时间边界（夜盘 / 跨日 / 周末）

### 2.4 禁止事项
- 禁止用 `time.Sleep` 等待异步；用 `synctest` 或 `assert.Eventually`
- 禁止依赖外部网络（mock 所有 HTTP / Redis）
- 禁止把 mock 数据导出到非 `_test.go` 文件
