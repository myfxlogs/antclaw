# 00 · 架构与共享契约

> 本文档定义信号 / 策略 / 回测层的共享接口、依赖注入约定、数据契约与错误码。**所有后续文档（01-13）依赖此处的定义**。

> **本地端口（`deploy/docker-compose.yaml`）**：`8082` → API（Connect JSON、`/health`、`/sse/*`）；`8081` → admin 静态站经 nginx（示例中直连 API 一律写 `8082`）。

---

## 1. 目标

1. 给信号 / 策略 / 回测三大子系统建立统一的"数据 Provider"抽象，避免各 Service 直接拼 SQL 重复造轮子；
2. 明确 RPC handler ↔ Service ↔ Provider ↔ Postgres 的分层；
3. 注册新增错误码到 `common.proto`；
4. 定义统一的"数据不足"语义。

---

## 2. 分层架构

```
┌───────────────────────────────────────────┐
│  RPC Handler (adapter/rpc/*.go)           │  仅负责 proto ↔ Service DTO 转换
├───────────────────────────────────────────┤
│  Service (service/<domain>/service.go)    │  业务编排、调用多个 Provider
├───────────────────────────────────────────┤
│  Provider 接口 (service/<domain>/types.go)│  抽象数据访问
├───────────────────────────────────────────┤
│  Repository (adapter/storage/postgres/)   │  纯 SQL，pgx 实现 Provider
└───────────────────────────────────────────┘
```

**禁止**：Handler 直接访问 `pgxpool.Pool`；Service 之间互相循环依赖（用 Provider 接口解耦）。

## 3. 必须新增的 Provider 接口

文件：`backend/internal/service/signals/providers.go`（新建）

```go
package signals

import (
    "context"
    "time"
)

// PriceProvider 价格数据
type PriceProvider interface {
    GetDailyBars(ctx context.Context, symbol string, from, to time.Time) ([]Bar, error)
    GetIntradayBars(ctx context.Context, symbol, interval string, from, to time.Time) ([]Bar, error)
    GetLatestPrice(ctx context.Context, symbol string) (*Bar, error)
}

// COTProvider COT 数据
type COTProvider interface {
    GetLatestAnalysis(ctx context.Context, contractCode string) (*COTAnalysis, error)
    GetAnalysisHistory(ctx context.Context, contractCode string, weeks int) ([]COTAnalysis, error)
    GetCurrencyExtremes(ctx context.Context, threshold float64) ([]COTAnalysis, error)
}

// MacroRegimeProvider 宏观状态
type MacroRegimeProvider interface {
    GetCurrent(ctx context.Context, symbol, timeframe string) (*RegimeSnapshot, error)
    GetHistory(ctx context.Context, symbol, timeframe string, lookback int) ([]RegimeSnapshot, error)
    GetTransitions(ctx context.Context, symbol string, since time.Time) ([]RegimeTransition, error)
}

// FactorProvider 因子排名（已有于 strategy/playbook.go，提升到 service/factors）
type FactorProvider interface {
    GetRanking(ctx context.Context, category string, asOf time.Time) (*RankingResult, error)
    GetSymbolFactors(ctx context.Context, symbol string, asOf time.Time) (*FactorBreakdown, error)
}

// VolProvider 波动率
type VolProvider interface {
    GetVIX(ctx context.Context) (float64, error)
    GetGARCH(ctx context.Context, symbol string) (*VolRegimeData, error)
    GetIVSurface(ctx context.Context, underlying string) (*IVSurface, error)
}

// FlowProvider 资金流背离
type FlowProvider interface {
    GetDivergence(ctx context.Context, pairA, pairB string, since time.Time) ([]FlowDivergence, error)
    GetTopDivergent(ctx context.Context, since time.Time, limit int) ([]FlowDivergence, error)
}

// SignalRepo 统一信号读写
type SignalRepo interface {
    SaveUnified(ctx context.Context, sig UnifiedSignalRecord) (int64, error)
    GetByID(ctx context.Context, id int64) (*UnifiedSignalRecord, error)
    GetRecentBySymbol(ctx context.Context, symbol string, limit int) ([]UnifiedSignalRecord, error)
    SaveOutcome(ctx context.Context, outcome SignalOutcome) error
    GetOutcomeStats(ctx context.Context, signalType, symbol string, horizon string, since time.Time) (*OutcomeStats, error)
}
```

## 4. 共享 DTO 定义

文件：`backend/internal/service/signals/types.go`（新建）

```go
package signals

import "time"

type Bar struct {
    Time   time.Time
    Symbol string
    Open, High, Low, Close, Volume float64
    Source string
}

type COTAnalysis struct {
    ReportDate     time.Time
    ContractCode   string
    NetPosition    int64
    COTIndex       float64 // 0-100
    Direction      string  // BULLISH/BEARISH/NEUTRAL
    SentimentScore float64
    WoWChange      int64
    ZScore         float64
    Percentile     float64
}

type RegimeSnapshot struct {
    Time          time.Time
    Symbol        string
    Timeframe     string
    UnifiedScore  float64 // -1..+1
    UnifiedLabel  string  // STRONG_BULL/BULL/NEUTRAL/BEAR/STRONG_BEAR
    HMMState      string
    HMMConfidence float64
    GARCHRegime   string
    VolRatio      float64
    ADXStrength   string
    ADXValue      float64
}

type RegimeTransition struct {
    Time      time.Time
    Symbol    string
    Timeframe string
    FromLabel string
    ToLabel   string
    FromScore float64
    ToScore   float64
    Severity  string // INFO/WARN/CRITICAL
}

type FactorBreakdown struct {
    Symbol    string
    AsOf      time.Time
    Momentum  float64
    LowVol    float64
    Trend     float64
    Carry     float64
    Crowding  float64
    Residual  float64
    Composite float64 // 加权后 0-100
}

type RankingResult struct {
    AsOf    time.Time
    Weights map[string]float64
    Items   []RankItem
}

type RankItem struct {
    Symbol    string
    Rank      int
    RawScore  float64
    NormScore float64 // 0-100
    Trend     string  // up/down/flat (相对上次快照)
    Breakdown FactorBreakdown
}

type FlowDivergence struct {
    Time          time.Time
    PairA, PairB  string
    Corr          float64
    BaselineMean  float64
    BaselineStd   float64
    ZScore        float64
    LeadLag       int
}

type VolRegimeData struct {
    Symbol      string
    Regime      string  // LOW/MEDIUM/HIGH/EXTREME
    Annualized  float64
    Percentile  float64
}

type IVSurface struct {
    Underlying string
    AtTheMoney float64
    Skew25Delta float64
    TermStructure []TermPoint
}

type TermPoint struct{ TenorDays int; IV float64 }

type UnifiedSignalRecord struct {
    ID             int64
    Symbol         string
    IssuedAt       time.Time
    Recommendation string  // STRONG_LONG/LONG/NEUTRAL/SHORT/STRONG_SHORT
    UnifiedScore   float64 // -1..+1
    Confidence     float64 // 0-1
    Components     map[string]float64
    MissingSubsys  []string
    WeightsUsed    map[string]float64
}

type SignalOutcome struct {
    SignalID       int64
    Horizon        string  // 1D/1W/2W/1M
    ReturnPct      float64
    DirectionMatch bool
    EvaluatedAt    time.Time
}

type OutcomeStats struct {
    SampleSize          int
    DirectionalAccuracy float64
    AvgReturn           float64
    HitRate             float64
    Sharpe              float64
    StdDev              float64
}
```

## 6. 数据不足（DATA_INSUFFICIENT）的统一语义

各 Service 必须遵守：

| 场景 | 阈值 | 行为 |
|------|------|------|
| `GetBias` | `cot_analyses` 至少有 4 条 | 否则返回 DATA_INSUFFICIENT |
| `GetRank` | 类别下至少 3 个标的有因子分 | 否则返回 DATA_INSUFFICIENT |
| `GetXFactors` | 6 大因子至少 4 个非空 | 否则降级，但 RPC 仍正常返回，标注 `missing_factors` |
| `GetRadar` | 类别下至少 5 个标的 | 否则 DATA_INSUFFICIENT |
| `GetIntensity` | 同标的过去 30 天 ≥ 20 个信号 | 否则返回 DATA_INSUFFICIENT |
| `GetUnified` | unified_signals 表中 24h 内有记录 | 否则 DATA_INSUFFICIENT |
| `GetAccuracy` | `signal_outcomes` 至少 30 条 | 否则 DATA_INSUFFICIENT |

返回方式（所有 Service 都用 `connect.NewError`）：
```go
return nil, connect.NewError(connect.CodeFailedPrecondition,
    fmt.Errorf("data insufficient: need ≥%d cot records, got %d", min, actual))
```

## 7. 依赖注入装配

修改 `backend/cmd/antclaw-api/main.go`，集中创建 Provider 单例：

```go
// providers wiring
priceProv      := postgres.NewPricePgProvider(dbpool)
cotProv        := postgres.NewCOTPgProvider(dbpool)
regimeProv     := postgres.NewRegimePgProvider(dbpool)
factorProv     := factors.NewProviderFromDB(dbpool)
volProv        := postgres.NewVolPgProvider(dbpool)
flowProv       := postgres.NewFlowPgProvider(dbpool)
signalRepo     := postgres.NewSignalRepoPg(dbpool)

// signals service
signalsSvc := signalssvc.NewService(signalssvc.Deps{
    Price:  priceProv,
    COT:    cotProv,
    Regime: regimeProv,
    Factor: factorProv,
    Vol:    volProv,
    Flow:   flowProv,
    Signal: signalRepo,
    Logger: logger,
})

signalsHandler := rpc.NewSignalsHandler(signalsSvc)
```

**禁止**：在 handler 内 `new()` 自己的 Provider。
