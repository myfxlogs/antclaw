## 1. 6 大因子定义

| 因子 | 计算 | 数据 |
|------|------|------|
| **Momentum** | 12-1 月动量 - 最近 1 月收益 | `price_daily` |
| **LowVol** | 60 日年化波动率取负百分位（低 = 高分）| `price_daily` |
| **Trend** | ADX(14) × sign(EMA20-EMA50) | `price_daily` |
| **Carry** | (FX) 利差 / (Crypto) 永续 funding rate / (股) 股息率 | `external_rates` 或 `onchain_metrics` |
| **Crowding** | 净持仓 / 未平仓合约 (COT) 的 Z-score 反向 | `cot_analyses` |
| **Residual** | 与同类资产（类别均值）日收益相关性的残差均值 | `price_daily` |

每个因子值标准化到 -3..+3（z-score），然后映射到 0-100 后再加权聚合 Composite。

## 2. 实现规范

### 2.1 因子接口

文件：`backend/internal/service/factors/factor.go`

```go
type Factor interface {
    Name() string
    Compute(ctx context.Context, symbol string, asOf time.Time) (raw float64, ok bool, err error)
}

type FactorEngine struct {
    factors []Factor
    weights map[string]float64   // 来自 signal_weight_config
    pool    *pgxpool.Pool
}

func (e *FactorEngine) ComputeBreakdown(ctx context.Context, symbol string, asOf time.Time) (*FactorBreakdown, error) {
    fb := &FactorBreakdown{Symbol: symbol, AsOf: asOf}
    rawValues := map[string]float64{}
    for _, f := range e.factors {
        v, ok, err := f.Compute(ctx, symbol, asOf)
        if err != nil { e.log.Warn("factor failed", "name", f.Name(), "err", err); continue }
        if !ok { continue }
        rawValues[f.Name()] = v
        setField(fb, f.Name(), v)   // reflection 或 switch
    }

    // 归一化：z-score → 0-100
    norm := normalizeZScores(rawValues, e.benchmark[asOf])
    composite := 0.0
    sumW := 0.0
    for name, val := range norm {
        w := e.weights[name]
        composite += w * val
        sumW += w
    }
    fb.Composite = composite / sumW
    return fb, nil
}
```

### 2.2 各因子实现

#### Momentum
文件：`factors/momentum.go`
```go
func (m *MomentumFactor) Compute(ctx, symbol, asOf) (float64, bool, error) {
    bars := priceProv.GetDailyBars(ctx, symbol, asOf.AddDate(-1, -1, 0), asOf)
    if len(bars) < 252+21: return 0, false, nil
    ret_12_1 := bars[len-21].Close / bars[0].Close - 1
    ret_1m   := bars[len-1].Close / bars[len-21].Close - 1
    return ret_12_1 - ret_1m, true, nil
}
```

#### LowVol
```go
returns := dailyReturns(bars[len-60:])
vol := stddev(returns) * sqrt(252)
return -vol, true, nil          // 取负，低波动 = 高分
```

#### Trend
```go
adx := indicators.ADX(bars, 14).last
ema20 := indicators.EMA(bars, 20).last
ema50 := indicators.EMA(bars, 50).last
sign := 1.0; if ema20 < ema50 { sign = -1 }
return adx * sign, true, nil    // ADX [0..100] × ±1
```

#### Carry
按资产类型分发：
```go
case isFX(symbol):
    base, quote := splitFX(symbol)
    rateBase  := ratesProv.GetPolicyRate(ctx, base, asOf)
    rateQuote := ratesProv.GetPolicyRate(ctx, quote, asOf)
    return rateBase - rateQuote, true, nil
case isCryptoPerp(symbol):
    f := onchainProv.GetLatest(ctx, symbol, "funding_rate")
    return f, true, nil
case isEquity(symbol):
    div := externalProv.GetDividendYield(ctx, symbol)
    return div, true, nil
```

需要新建表 `external_rates`：
```sql
CREATE TABLE IF NOT EXISTS external_rates (
    asof_date DATE NOT NULL,
    currency  VARCHAR(8) NOT NULL,
    policy_rate DOUBLE PRECISION,
    source     VARCHAR(32),
    PRIMARY KEY (asof_date, currency)
);
```
worker 任务从 FRED 拉取 EURIBOR/USD-FFR/JPY-CNY/...

#### Crowding
```go
code := ResolveCOTCode(symbol)
cot := cotProv.GetLatestAnalysis(ctx, code)
if cot == nil: return 0, false, nil
return -cot.ZScore, true, nil   // 极端拥挤 = 低分（反向）
```

#### Residual
```go
category := categoryOf(symbol)
peers := Categories[category] - {symbol}
peer_returns_avg := mean of peers' last-30d returns
my_returns := my_last_30d_returns
beta, alpha := ols(my_returns, peer_returns_avg)
residuals := my_returns - (alpha + beta*peer_returns_avg)
return mean(residuals[-7:]), true, nil
```

weights := signal_weight_config.GetActive().weights

## 4. Provider 集成

`FactorProvider.GetRanking(category, asOf)` SQL：
```sql
WITH latest AS (
    SELECT MAX(time) AS t FROM factor_rankings WHERE time <= $2
)
SELECT e.symbol, e.rank, e.raw_score, e.norm_score, e.breakdown,
       fr.weights
FROM factor_ranking_entries e
JOIN factor_rankings fr ON fr.snapshot_id = e.snapshot_id
WHERE fr.time = (SELECT t FROM latest)
ORDER BY e.rank ASC
```

`GetSymbolFactors(symbol, asOf)` 直接调 `engine.ComputeBreakdown`（实时计算，避免依赖 snapshot 写入完成）。
