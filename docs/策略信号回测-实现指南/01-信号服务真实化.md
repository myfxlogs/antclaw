## 2. 算法详细规范

### 2.1 GetBias — 方向偏好

**输入**：`pair`（如 EURUSD）, `timeframe`（1h/4h/1d）

**算法**：
```
contract_code = symbol_to_cot_code(pair)   // 见 §4 映射表
cot = COTProvider.GetLatestAnalysis(contract_code)
regime = RegimeProvider.GetCurrent(pair, timeframe)
factor = FactorProvider.GetSymbolFactors(pair, now)

# 三因子加权
score = 0.4 * cot.SentimentScore        # COT 情绪：-1..+1
      + 0.4 * regime.UnifiedScore        # 宏观状态：-1..+1
      + 0.2 * tanh(factor.Momentum)      # 动量归一：-1..+1

direction = "bullish"  if score > 0.2 else
            "bearish"  if score < -0.2 else
            "neutral"

confidence = min(0.95, abs(score) * (1 - regime_uncertainty))
# regime_uncertainty = 1 - regime.HMMConfidence
```

**输出**：填充 `BiasData{Pair, Direction, Confidence, Timeframe}`

**边界**：
- `cot` 为 nil → 退化为只用 regime + factor，权重重分配 (regime=0.7, factor=0.3)
- `regime` 为 nil → 退化为 COT + factor (cot=0.7, factor=0.3)
- 都为 nil → 返回 `DATA_INSUFFICIENT`

### 2.2 GetRank — 货币强弱排名

**输入**：`category`（majors/crosses/crypto/all）

**算法**：
```
1. 调用 FactorProvider.GetRanking(category, today)
2. 排名变化趋势：对比上一交易日快照
   - rank_today < rank_yesterday → trend="up"
   - rank_today > rank_yesterday → trend="down"
   - 差 ≤ 1 → trend="flat"
3. 输出按 NormScore 降序的 RankItem 列表
```

**Category → Symbol 映射** 写在 `internal/service/signals/categories.go`：
```go
var Categories = map[string][]string{
    "majors":  {"EURUSD","GBPUSD","USDJPY","USDCHF","AUDUSD","USDCAD","NZDUSD"},
    "crosses": {"EURGBP","EURJPY","GBPJPY","EURAUD","AUDJPY","CHFJPY","EURCHF"},
    "crypto":  {"BTCUSDT","ETHUSDT","SOLUSDT","BNBUSDT","XRPUSDT"},
    "indices": {"SPX","NDX","DJI","RUT","DAX"},
}
```

**边界**：类别下非空因子排名 < 3 → DATA_INSUFFICIENT。

### 2.3 GetXFactors — 多因子分解

**输入**：`pair`

**算法**：
```
fb = FactorProvider.GetSymbolFactors(pair, now)
weights = SignalWeightConfig.GetActive()      // 表 signal_weight_config WHERE is_active

factors = []
for name, val in {Momentum, LowVol, Trend, Carry, Crowding, Residual}:
    if val == nil: continue
    direction = "positive" if val > 0 else "negative"
    factors.append({
        Name: name,
        Weight: weights[name],
        Direction: direction,
        Description: describe(name, val),
    })

composite = sum(weights[n] * factor[n] for n in factors) / sum(weights)
composite_signal = "long" if composite > 0.3 else
                   "short" if composite < -0.3 else "neutral"
```

**describe()** 文案模板，写在 `internal/service/signals/descriptions.go`：
```go
"Momentum":  "12W momentum %s (%.2f)",         // strong/weak
"LowVol":    "Volatility %s vs peers (%.2f)",
"Trend":     "Trend quality %s, ADX=%.1f",
...
```

**边界**：6 个因子至少 4 个非空，否则在响应中 `composite_signal=""` 但 `factors` 仍返回。

### 2.4 GetRadar — 雷达图

**输入**：`category`

**算法**（每个标的一个数据点，无下钻）：
```
symbols = Categories[category]
points = []
for sym in symbols:
    factor = FactorProvider.GetSymbolFactors(sym, now)
    regime = RegimeProvider.GetCurrent(sym, "1d")
    if factor == nil || regime == nil: skip

    x = factor.Composite           # 0-100
    y = regime.UnifiedScore        # -1..+1
    quadrant = classify(x, y)      # "high_bull"/"high_bear"/"low_bull"/"low_bear"
    strength = abs(y) * (x / 100)
    points.append({Pair: sym, X: x, Y: y, Quadrant: quadrant, Strength: strength})
```

**classify**：
```go
func classify(x, y float64) string {
    isHigh := x >= 60
    isBull := y > 0.1
    switch {
    case isHigh && isBull: return "high_bull"
    case isHigh && !isBull: return "high_bear"
    case !isHigh && isBull: return "low_bull"
    default: return "low_bear"
    }
}
```

### 2.5 GetIntensity — 信号强度

**输入**：`pair`

**算法**：
```
recent = SignalRepo.GetRecentBySymbol(pair, 100)  // 最近 100 条
if len(recent) < 20: return DATA_INSUFFICIENT

scores = [abs(s.UnifiedScore) for s in recent]
current = scores[0]
percentile_30d = rank(current, scores) / len(scores) * 100

label = "weak"     if percentile_30d < 30 else
        "moderate" if percentile_30d < 60 else
        "strong"   if percentile_30d < 85 else "extreme"
```

### 2.6 GetUnified — 统一信号

**输入**：`pair`

**算法**：
```
sig = SignalRepo.GetRecentBySymbol(pair, 1)
if not sig: 触发实时计算 ComputeUnified(pair) 并入库

return {
    Pair: sig.Symbol,
    Direction: recommendation_to_direction(sig.Recommendation),
    Confidence: sig.Confidence,
    ContributingFactors: top_3_components(sig.Components),
}
```

**ComputeUnified（实时计算函数）** 写在 `signals/unified_compute.go`：
```
components = {
    "cot":    cot.SentimentScore,           # -1..+1
    "macro":  regime.UnifiedScore,
    "factor": tanh(factor.Composite/100 * 2 - 1),
    "flow":   flow_score(pair),             # FlowProvider 加工
    "vol":    vol_score(pair),              # 高波动惩罚
    "season": seasonal_score(pair, now),    # 季节性
}

weights = SignalWeightConfig.GetActive().Weights
unified_score = sum(weights[k] * components[k]) / sum(weights[k])
                                                  for k in components

recommendation =
    "STRONG_LONG"  if unified_score >= 0.6  else
    "LONG"         if unified_score >= 0.2  else
    "NEUTRAL"      if abs(unified_score)<0.2 else
    "SHORT"        if unified_score <= -0.2 else "STRONG_SHORT"

confidence = sigmoid(abs(unified_score) * 4) * data_completeness
data_completeness = (#non-nil components) / 6
```

写入 `unified_signals` 表后返回 `signal_id`。

## 3. 数据访问 SQL（写入对应 Provider）

### 3.1 PriceProvider.GetDailyBars
```sql
SELECT time, symbol, open, high, low, close, volume, source
FROM price_daily
WHERE symbol = $1 AND time >= $2 AND time <= $3
ORDER BY time ASC
```

### 3.2 COTProvider.GetLatestAnalysis
```sql
SELECT report_date, contract_code, net_position, cot_index, direction,
       sentiment_score, wow_change, zscore, percentile
FROM cot_analyses
WHERE contract_code = $1
ORDER BY report_date DESC
LIMIT 1
```

### 3.3 RegimeProvider.GetCurrent
```sql
SELECT time, symbol, timeframe, unified_score, unified_label,
       hmm_state, hmm_confidence, garch_regime, vol_ratio,
       adx_strength, adx_value
FROM regime_overlay_history
WHERE symbol = $1 AND timeframe = $2
ORDER BY time DESC
LIMIT 1
```

### 3.4 FlowProvider.GetTopDivergent
```sql
SELECT time, pair_a, pair_b, corr, baseline_mean, baseline_std,
       z_score, lead_lag
FROM flow_divergence_history
WHERE time >= $1
ORDER BY abs(z_score) DESC
LIMIT $2
```

### 3.5 SignalRepo.GetRecentBySymbol
```sql
SELECT id, symbol, issued_at, recommendation, unified_score,
       confidence, components, missing_subsys, weights_used
FROM unified_signals
WHERE symbol = $1
ORDER BY issued_at DESC
LIMIT $2
```

## 4. Symbol → COT contract_code 映射

写在 `internal/service/signals/cot_mapping.go`：

```go
var SymbolToCOTContract = map[string]string{
    "EURUSD": "099741", "GBPUSD": "096742", "USDJPY": "097741",
    "USDCHF": "092741", "AUDUSD": "232741", "USDCAD": "090741",
    "NZDUSD": "112741",
    "BTCUSDT": "133741", "ETHUSDT": "146021",
    "GOLD":   "088691", "XAUUSD": "088691",
    "WTI":    "067651", "SILVER":"084691",
    "SPX":    "13874A", "NDX":   "209742",
}

func ResolveCOTCode(symbol string) (string, bool) {
    code, ok := SymbolToCOTContract[strings.ToUpper(symbol)]
    return code, ok
}
```

## 5. Service 实现骨架

文件：`backend/internal/service/signals/service.go`（**重写**）

```go
package signals

type Deps struct {
    Price  PriceProvider
    COT    COTProvider
    Regime MacroRegimeProvider
    Factor FactorProvider
    Vol    VolProvider
    Flow   FlowProvider
    Signal SignalRepo
    Logger *slog.Logger
}

type Service struct{ deps Deps }

func NewService(d Deps) *Service { return &Service{deps: d} }

func (s *Service) GetBias(ctx context.Context, pair, tf string) (*BiasData, error) {
    code, ok := ResolveCOTCode(pair)
    var cot *COTAnalysis
    if ok { cot, _ = s.deps.COT.GetLatestAnalysis(ctx, code) }
    regime, _ := s.deps.Regime.GetCurrent(ctx, pair, tf)
    fb,    _ := s.deps.Factor.GetSymbolFactors(ctx, pair, time.Now())

    if cot == nil && regime == nil && fb == nil {
        return nil, ErrDataInsufficient
    }
    score, conf := combineBias(cot, regime, fb)
    return &BiasData{
        Pair: pair, Timeframe: tf,
        Direction: directionLabel(score),
        Confidence: conf,
    }, nil
}
// ... 其余 RPC 类似
```

**combineBias / directionLabel / classify / describe** 等纯函数写在 `signals/calc.go`，单测覆盖率 ≥ 90%。

## 9. 风险与回退

| 风险 | 缓解 |
|------|------|
| `cot_analyses` 空 → bias 无法计算 | 先跑 `worker` 至少一轮 analyzer；如仍空，DATA_INSUFFICIENT |
| `factor_rankings` 空 | 先完成文档 `11-因子库扩展.md` 的因子计算 worker |
| `regime_overlay_history` 空 | 由 `worker analyzer.go` 周期写入；初始化时 backfill 最近 30 天 |
| Symbol 不在映射表 | 返回 DATA_INSUFFICIENT，并记录 `signals.unmapped_symbol` 日志计数 |
