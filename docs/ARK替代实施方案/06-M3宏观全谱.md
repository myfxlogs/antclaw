## 2. T1 11 家宏观薄 client

> 接口契约见 `02-Vendor薄客户端规范.md`。本节给出每家 vendor 的端点细节与字段重点。

### 2.1 BIS（国际清算银行）

- BaseURL：`https://stats.bis.org/api/v2`
- 关键端点：
  - `/data/{flow}/{key}/all?format=jsondata`
  - 常用 flow：`WS_CBPOL`（央行政策利率）、`WS_CREDIT_GAP`（信贷缺口）、`WS_EER`（实际有效汇率）
- 限速：低，需要 `Cache-Control` 缓存
- 实现要点：BIS 用 SDMX-JSON，需要解析 `dataSets[0].series` 嵌套结构；建议在 `parse.go` 中提供 `flattenSDMX(resp)` 工具函数

### 2.2 IMF（国际货币基金组织）

- BaseURL：`http://dataservices.imf.org/REST/SDMX_JSON.svc`
- 关键端点：`/CompactData/{dataset}/{key}`
- 常用数据集：`WEO`（World Economic Outlook）、`IFS`（International Financial Statistics）
- 字段：与 BIS 同为 SDMX-JSON

### 2.3 World Bank

- BaseURL：`https://api.worldbank.org/v2`
- 端点：`/country/{country_code}/indicator/{indicator}?format=json`
- 返回：`[meta, [points]]` 双元素数组（注意首元素是 meta）
- 常用 indicator：`NY.GDP.MKTP.CD`（GDP）、`FP.CPI.TOTL.ZG`（CPI）、`SL.UEM.TOTL.ZS`（失业率）

### 2.4 ECB（欧洲央行）

- BaseURL：`https://sdw-wsrest.ecb.europa.eu/service`
- 端点：`/data/{flow}/{key}?format=jsondata`
- 常用 flow：`EXR`（汇率）、`FM`（金融市场）、`STS`（短期统计）

### 2.5 Eurostat

- BaseURL：`https://ec.europa.eu/eurostat/api/dissemination/statistics/1.0/data`
- 端点：`/{dataset}?format=JSON&lang=EN&{filters}`
- 常用 dataset：`prc_hicp_manr`（HICP 同比）、`une_rt_m`（失业率月度）

### 2.6 OECD

- BaseURL：`https://stats.oecd.org/sdmx-json/data`
- 端点：`/{dataset}/{filter}/{agency}?startTime=...&endTime=...`
- 常用 dataset：`MEI`（主要经济指标）、`KEI`（关键经济指标）

### 2.7 SNB（瑞士国家银行）

- BaseURL：`https://data.snb.ch/api`
- 端点：`/cube/{cube_id}/data/csv?fromDate=...&toDate=...`
- 返回 CSV，需要在 `parse.go` 中提供 CSV 解析

### 2.8 TradingEconomics

- BaseURL：`https://api.tradingeconomics.com`
- 鉴权：`?c=guest:guest`（免费）或带 api_key
- 端点：`/calendar`、`/historical/country/{country}/indicator/{indicator}`
- 限速极低：免费 100 次/天，必须缓存

### 2.9 DTCC

- BaseURL：`https://www.dtcc.com/dtcc-connection`
- 多为公开下载 CSV/Excel，无标准 REST API
- 实现：`GetSwapDataRepository(ctx, asset_class, date)` 抓取并解析 CSV

### 2.10 US Treasury

- BaseURL：`https://api.fiscaldata.treasury.gov/services/api/fiscal_service`
- 端点：`/v2/accounting/od/avg_interest_rates`、`/v1/accounting/dts/dts_table_1`、`/v2/accounting/od/securities_outstanding`
- 关键收益率：`/v2/accounting/od/daily_treasury_yield_curve`（日收益率曲线）

### 2.11 FedWatch（CME）

- 数据源：CME Group 公开 JSON（路径不稳定，需在代码注释中标注 ARK 当时使用的路径，并加注 fallback 抓取 HTML）
- 端点示例：`https://www.cmegroup.com/services/cme-group-tools-api/fed-watch-tool/probability/{date}.json`
- 输出：每个利率区间的概率
- 注意：CME 偶尔重构路径，必须加 `errs.External` 容错与降级

## 3. T2 FRED 增强

### 3.1 service/macro/alerts.go

迁移 ARK `service/fred/alerts.go`。

告警类型：

| Alert | 触发条件 |
|---|---|
| `regime_change` | 失业率 / 通胀 / 利差超过 z-score 阈值 |
| `yield_inversion` | 2s10s 由正转负或由负转正 |
| `cpi_spike` | CPI 同比变化超过 0.3pp |
| `pmi_break` | PMI 跨越 50 |

实现：每次 FRED 同步后执行 evaluator，触发的告警写入 `macro_alerts` 表，并通过 SSE `stream:macro_alerts` 推送。

### 3.2 service/macro/carry_monitor.go

迁移 ARK `service/fred/carry_monitor.go`。

计算 G10 货币的 carry 指标：

```
carry_ccy = short_rate_ccy - short_rate_USD
adjusted_carry = carry_ccy * (1 - vol_z) * (1 - cot_extreme_factor)
```

输出每个货币的排名与 z-score；持久化于 `carry_snapshots` 表。

### 3.3 service/macro/composites.go

迁移 ARK `service/fred/composites.go`。

复合指标：

| 指标 | 公式 |
|---|---|
| `liquidity_index` | M2 - WALCL（联储资产）+ TGA |
| `financial_conditions` | (high_yield_spread + dollar_index_z + vix_z) / 3 |
| `growth_pulse` | (ism_pmi + nfp_3mma + retail_sales_yoy) / 3 |

落 `macro_composites` 表，按日刷新。

### 4.1 文件

```
├── service.go            # 路由器：source → 对应 vendor client
├── fred_carry.go         # 转发 service/macro/carry_monitor

```

### 4.2 路由实现

```go
func (s *Service) GetSeries(ctx context.Context, in *v1.GetMacroSeriesRequest) (*v1.GetMacroSeriesResponse, error) {
    switch in.Source {
    case "bis":         return s.getBIS(ctx, in)
    case "imf":         return s.getIMF(ctx, in)
    case "worldbank":   return s.getWorldBank(ctx, in)
    case "ecb":         return s.getECB(ctx, in)
    case "eurostat":    return s.getEurostat(ctx, in)
    case "oecd":        return s.getOECD(ctx, in)
    case "snb":         return s.getSNB(ctx, in)
    case "te":          return s.getTradingEconomics(ctx, in)
    case "dtcc":        return s.getDTCC(ctx, in)
    case "treasury":    return s.getTreasury(ctx, in)
    default:            return nil, errs.NotFound
    }
}
```

### 4.3 缓存策略

- 所有 `GetSeries` 调用结果落 `macro_series_cache` 表，TTL = 6 小时
- key = SHA256(source + series_id + start + end)
- 命中时直接返回，并打 `cache_hit` metric

### 5.2 收益率曲线构建

```go
type Curve struct {
    Date   time.Time
    Tenors map[string]float64    // "1M","3M","6M","1Y","2Y","3Y","5Y","7Y","10Y","20Y","30Y"
}
```

数据来源：`apiclient/treasury` 的 `/daily_treasury_yield_curve` 端点。

### 5.3 分析

```
curve_2s10s = yield_10y - yield_2y
curve_3m10y = yield_10y - yield_3m
regime:
    if curve_2s10s < -0.1: inverted
    elif curve_2s10s > prev_30d_avg + 0.2: steepening
    elif curve_2s10s < prev_30d_avg - 0.2: flattening
    else: normal
```

## 9. 数据库迁移

```sql
CREATE TABLE macro_series_cache (
  cache_key TEXT PRIMARY KEY,
  source TEXT NOT NULL,
  series_id TEXT NOT NULL,
  payload JSONB NOT NULL,
  expires_at TIMESTAMPTZ NOT NULL
);
CREATE INDEX idx_macro_cache_expires ON macro_series_cache (expires_at);

CREATE TABLE macro_alerts (
  id UUID PRIMARY KEY,
  kind TEXT NOT NULL,
  severity TEXT NOT NULL,
  message TEXT NOT NULL,
  data JSONB,
  triggered_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
CREATE INDEX idx_macro_alerts_kind ON macro_alerts (kind, triggered_at DESC);

CREATE TABLE carry_snapshots (
  date DATE NOT NULL,
  ccy TEXT NOT NULL,
  carry DOUBLE PRECISION NOT NULL,
  adjusted DOUBLE PRECISION NOT NULL,
  rank INT NOT NULL,
  PRIMARY KEY (date, ccy)
);

CREATE TABLE macro_composites (
  date DATE PRIMARY KEY,
  liquidity_index DOUBLE PRECISION,
  financial_conditions DOUBLE PRECISION,
  growth_pulse DOUBLE PRECISION,
  details JSONB
);

CREATE TABLE fedwatch_snapshots (
  meeting_date DATE NOT NULL,
  taken_at TIMESTAMPTZ NOT NULL,
  distribution JSONB NOT NULL,
  PRIMARY KEY (meeting_date, taken_at)
);

CREATE TABLE treasury_curves (
  date DATE PRIMARY KEY,
  tenors JSONB NOT NULL,
  curve_2s10s DOUBLE PRECISION,
  curve_3m10y DOUBLE PRECISION,
  regime TEXT
);
```
