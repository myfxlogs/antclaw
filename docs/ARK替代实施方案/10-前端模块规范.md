# 10 · 前端模块规范

> 全部前端代码必须满足：**仅 Connect-RPC + SSE**；禁止 fetch/axios/WebSocket/setInterval（业务用途）。
> 本文给出每个新增/扩展模块的目录、入口、状态、错误模板，以及通用约束。

---

## 1. 通用约束

### 1.1 协议层

```ts
// 唯一允许的 HTTP 客户端
import { createClient } from '@connectrpc/connect'
import { createConnectTransport } from '@connectrpc/connect-web'

const transport = createConnectTransport({
  baseUrl: import.meta.env.VITE_API_BASE_URL,
  // 加密 envelope 走 CryptoService.PostEnvelope，不暴露 fetch
})

// 唯一允许的事件流
const evt = new EventSource('/sse/<channel>')
```

### 1.2 状态机模式

每个页面必须用以下三态显式渲染：

```ts
type AsyncState<T> =
  | { status: 'idle' }
  | { status: 'loading' }
  | { status: 'success'; data: T }
  | { status: 'error'; error: string }
```

错误时统一展示 `<ErrorBanner>`；loading 时统一展示 `<Skeleton>`。

### 1.3 不允许的模式

| 反例 | 替代 |
|---|---|
| `setInterval(loadData, 5000)` | 使用 `EventSource` 订阅 SSE |
| `await fetch('/api/...')` | 使用 connect-web client |
| `new WebSocket(...)` | 使用 SSE |
| `axios.get(...)` | 使用 connect-web client |
| `setTimeout(loadData, 1000)` 用作业务轮询 | 使用 SSE |
| `setTimeout(() => setToast(null), 2500)` | ✅ 允许（UI 反馈） |

## 4. 国际化（i18n）

每个新模块必须在 `src/locales/{zh-CN,en-US}.json` 添加 namespace：

```json
{
  "options": {
    "gex": {
      "title": "Gamma Exposure",
      "totalGex": "Total GEX",
      "zeroGamma": "Zero Gamma",
      "loading": "加载中...",
      "error": "数据加载失败"
    }
  }
}
```

中英两份 key 必须完全对齐；缺失的 key CI 会失败（详见 `docs/AntClaw-国际化规范.md`）。

---

## 5. 测试

每个 page 至少包含：

- **渲染测试**：mock connect 客户端，断言初始状态、loading、success、error 四态渲染
- **错误处理**：mock 抛出 Connect Error，断言 `<ErrorBanner>` 出现
- **SSE 测试**（如适用）：mock `EventSource`，断言事件触发后状态正确更新

工具：`vitest` + `@testing-library/react`。覆盖率目标 ≥ 60%。
