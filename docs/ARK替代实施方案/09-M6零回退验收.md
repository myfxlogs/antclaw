## 4. 端到端场景脚本

每个场景由 `scripts/e2e/<scenario>.sh` 提供。

### 4.1 SC-1：COT 摘要

```bash
TOKEN=$(scripts/e2e/login.sh)
curl -s -X POST http://localhost:8082/antclaw.v1.COTService/GetSummary \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"asset":"EUR"}' | jq '.'
# 期望：返回 net_position、percentile_rank、signal 字段
```

### 4.2 SC-2：FRED 告警 SSE

```bash
curl -N -H "Authorization: Bearer $TOKEN" http://localhost:8082/sse/macro_alerts &
PID=$!
sleep 30
kill $PID
# 期望：30s 内至少收到 1 条心跳或告警事件
```

### 4.3 SC-3：GEX

```bash
curl -s -X POST http://localhost:8082/antclaw.v1.OptionsService/GetGEX \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"asset":"BTC","venue":"deribit"}' | jq '.totalGex'
# 期望：返回非零数值；.strikes 数组长度 > 10
```

### 4.4 SC-4：Walk-Forward

```bash
curl -s -X POST http://localhost:8082/antclaw.v1.BacktestService/RunWalkForward \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer $TOKEN" \
  -d '{"strategyId":"cot_eur_default","start":"...","end":"...","trainDays":252,"testDays":63}' \
  | jq '.windows | length'
# 期望：windows 数组长度 ≥ 5
```

## 6. 数据可用性验收

```sql
-- 各核心表至少有最近 7 天数据
SELECT table_name, MAX(time) AS latest
FROM (
  SELECT 'cot_positions' AS table_name, MAX(report_date) AS time FROM cot_positions
  UNION ALL SELECT 'data_snapshots', MAX(time) FROM data_snapshots WHERE source='fred'
  UNION ALL SELECT 'calendar_events', MAX(scheduled_at) FROM calendar_events
  UNION ALL SELECT 'onchain_metrics_extended', MAX(time) FROM onchain_metrics_extended
  UNION ALL SELECT 'iv_surface_snapshots', MAX(taken_at) FROM iv_surface_snapshots
  UNION ALL SELECT 'defi_tvl_history', MAX(time) FROM defi_tvl_history
  UNION ALL SELECT 'sec_filings', MAX(filed_at) FROM sec_filings
  UNION ALL SELECT 'sentiment_cboe_pc', MAX(date) FROM sentiment_cboe_pc
) t
WHERE time IS NULL OR time < now() - INTERVAL '7 days';
-- 期望：返回 0 行
```

## 7. Job 健康验收

```bash
docker exec antclaw-redis redis-cli --scan --pattern 'jobs:status:*' | wc -l
# 期望：≥ 41（M1=18 + M3=11 + M4=12，可能更多）

# 失败 Job 列表
for k in $(docker exec antclaw-redis redis-cli --scan --pattern 'jobs:status:*'); do
  echo -n "$k: "
  docker exec antclaw-redis redis-cli get "$k" | jq -r '.status'
done | grep -E 'failed' || echo "OK: 无 failed Job"
```
