# AlfQ · 安卓客户端设计文档

> AlfQ = Alfa + Quant。交易员的社交终端。
> 设计参照：X (Twitter) / Threads — 极简、深色、卡片式、实时。
> 后端复用 AntClaw，新增 Chat/Circle/Feed Service。

---

## 一、产品定位

**一句话**：交易员版的 X，信号驱动的社交网络。

- **不是**：Bloomberg 终端的替代品（不做复杂图表，那是 web/admin 的事）
- **是**：以交易信号为纽带、以私聊为协作工具的移动社交应用
- **核心差异**：**信号即内容** — AntClaw 的实时信号自动生成帖子，用户围绕信号讨论

---

## 二、核心功能矩阵

| 模块 | 功能 | 优先级 |
|---|---|---|
| **Feed（信息流）** | 关注者动态 + 信号推送 + 热门讨论 | P0 |
| **Signal（信号）** | 实时信号卡片（方向/置信度/品种），一键订阅 | P0 |
| **Alert（警报）** | 价格突破 / 信号变更 / 宏观事件推送 | P0 |
| **Chat（私聊）** | 一对一 / 群组文字聊天，支持分享信号卡片 | P1 |
| **Circle（圈子）** | 按品种/策略建圈子，圈内讨论 + 共享信号 | P1 |
| **Profile（个人）** | 交易者主页：战绩/关注/粉丝/历史信号 | P0 |
| **Discover（发现）** | 热门交易员 / 推荐圈子 / 热门品种 | P1 |

## 三、信息架构（底部导航）

```
┌─────────────────────────────────────┐
│  Feed     发现     发布      我     │
│  (首页) (Discover)  (+)     (Me)   │
└─────────────────────────────────────┘
```

### 3.1 Tab 1：Feed（首页）

- 混合信息流：关注者帖子 + 系统信号卡片 + 系统警报卡片
- 顶部：横向滚动的信号概览条（自选品种方向/置信度一览，点开进入详情）
- 帖子类型：`text` / `signal_card` / `alert_card` / `chart_share` / `trade_share`
- 交互：点赞、评论、转发（引用）、分享到私聊
- 筛选器：全部 / 仅信号 / 仅帖子

**系统信号自动发帖规则**：
- 发帖触发条件：信号方向变更（BULL→BEAR / BEAR→BULL / →NEUTRAL）时自动生成帖子
- 去重策略：同一品种同方向 **4 小时内不重复发帖**
- 发帖者身份：`系统信号`（官方账号，蓝 V 标识）
- 帖子内容：品种 + 方向 + 置信度 + 关键因子摘要
- 用户手动分享信号到 Feed 不受此限制

### 3.2 Tab 2：发现

- 搜索：交易员 / 品种 / 圈子
- 推荐关注：热门交易员（按战绩排序）
- 热门圈子：活跃圈子推荐
- 热门品种：当前讨论最多的品种

### 3.3 Tab 3：发布（+）

- 发布纯文本帖子
- 附带信号卡片（选择当前关注的品种信号）
- 附带图表截图
- 选择可见范围：公开 / 圈子 / 仅关注者

### 3.4 Tab 4：我

- 头像 + 昵称 + 一句话简介
- 战绩卡片：胜率 / 盈亏比 / 夏普 / 关注者 / 正在关注（用户自选公开项）
- 绿标/蓝标 认证标识
- 我的帖子 / 历史信号
- 交易账号（MT4/MT5 只读连接管理）
- 我的警报（订阅管理 + 阈值修改 + 静默时段）
- 交易市场（Marketplace 入口）
- 设置：通知 / 隐私 / 外观（深色/浅色）/ 数据源配置

## 五、设计原则

1. **暗色优先**：交易员夜间看盘，深色主题为默认
2. **信息密度适中**：不像 Bloomberg 那样拥挤，也不像 Instagram 那样稀疏
3. **动作最少化**：看信号 → 订阅警报 → 发布讨论，三步内完成
4. **离线可用**：Room 缓存最近 200 条 Feed / 信号，无网络也能浏览
5. **隐私优先**：私聊端到端加密（Signal Protocol），战绩可选择隐藏
6. **优雅降级**：RPC 超时返回缓存数据；SSE 断线 5s 自动重连，指数退避（1s→2s→4s→max 30s）；网络恢复后优先拉增量
7. **新增 Service 归属 AntClaw v1**：Feed/Chat/Circle/Trader/Marketplace Service 注册到 `proto/antclaw/v1/`，保持与现有接口一致的版本号

## 六、设计决策

| # | 决策 | 结论 |
|---|---|---|
| 1 | **信号卡片设计** | 方案 C：Feed 纯数字+方向，详情页完整 K 线 |
| 2a | **战绩公开指标** | 用户自选，默认安全项，敏感项手动开启带风险提示 |
| 2b | **交易员验证** | 三层身份：普通 / 🟢轻量（MT≥30笔，M0.5） / 🔵精英（人工审核，M3） |
| 3 | **内容审核** | 分阶段：冷启动期信任+举报 → 成长期 AI 预筛 |
| 4 | **盈利模式** | 初期免费，后期后台开启付费；Marketplace 抽佣 30/25/20（后台可调），试用期可选 |
| 5 | **iOS 同步** | Android 先行，3 个月后评估 iOS |
| 6 | **MT 接入** | 首版只读（账号管理+历史数据），策略执行远期；策略可绑定 MT 自动执行（非跟单） |
| 7 | **导航结构** | 4 Tab（Feed / 发现 / 发布 / 我）；信号并入 Feed 顶部，警报并入「我」→ 设置 |

## 八、术语使用规范

### 8.1 品牌名称

| 用途 | 规范 | 示例 |
|-----|-----|-----|
| **品牌展示** | AlfQ（保留独特拼写） | APP 名称、Logo、宣传材料 |
| **代码/API** | 使用标准术语 `alpha` | 变量名、函数名、接口字段 |
| **文档描述** | Alpha（金融术语标准拼写） | 技术文档、API 说明 |

### 8.2 金融术语

| 术语 | 规范拼写 | 说明 |
|-----|---------|-----|
| 阿尔法系数 | **Alpha** | 投资超额收益指标 |
| 贝塔系数 | **Beta** | 市场风险指标 |
| 信号方向 | **Bull/Bear** | 看涨/看跌 |
| 成交量 | **Volume** | 交易数量 |

### 8.3 Logo 设计规范

- **主元素**：希腊字母 α（Alpha） + Q 字母组合
- **配色**：金色系（#D4AF37 / #E6C65C）+ 深色背景（#141D22 / #0F172A）
- **辅助元素**：上升趋势线、成交量柱（绿色上涨/红色下跌）

### 8.4 代码命名规范

```
✅ 推荐：
- alphaCoefficient（变量）
- calculateAlpha（函数）
- AlphaStrategy（类名）

❌ 不推荐：
- alfaCoefficient（非标准拼写）
- ALPHA（全大写仅用于常量）
```
