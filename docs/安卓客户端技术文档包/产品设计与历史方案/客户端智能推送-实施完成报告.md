## 五、架构验证

### 全链路数据流

```
Worker 推送检测器                      Android 客户端
      │                                      │
  push_calendar ──┐                          │
  push_digest ────┤                          │
  push_macro ─────┤                          │
  push_cot ───────┤                          │
      │           ▼                          │
      │  sendIfNotPushed                     │
      │    ├─ alreadyPushed (DB去重)          │
      │    ├─ svc.Send ──────────────────    │
      │    │   ├─ Redis SETNX (短时去重)      │
      │    │   ├─ loadPrefs (偏好加载)        │
      │    │   ├─ INSERT notifications (落库) │
      │    │   ├─ shouldDeliverLive (过滤)    │
      │    │   └─ Redis PUBLISH ──────────► user:{uuid}:notifications
      │    └─ recordPush (记录状态)           │
      │                                      ▼
      │                              /sse/notifications
      │                                      │
      │                         NotificationSseClient
      │                            (OkHttp 长连接)
      │                                      │
      │                         NotificationViewModel
      │                            ├─ 未读计数更新
      │                            ├─ 通知列表更新
      │                            ├─ 前台: Snackbar
      │                            └─ 后台: 系统通知
```
