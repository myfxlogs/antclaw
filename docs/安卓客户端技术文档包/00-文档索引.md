# 安卓客户端技术文档包索引

## 文档包目的

本目录为 Android 客户端独立开发提供统一技术依据。客户端 AI Agent 应先阅读本索引，再按任务跳转到对应文档。服务端 AI Agent 在另一台开发环境执行时，应以 `09-服务端配套改造优化文档.md` 为入口。`07-文档质量评审与落地边界.md` 是必读边界文档，用于避免误实现管理端接口。

## 固定约定

- **API 根地址**：`https://api.alfq.org/`
- **RPC 协议**：Connect-RPC over HTTPS
- **SSE 地址**：`https://api.alfq.org/sse/notifications`
- **认证头**：`Authorization: Bearer <access_token>`
- **管理端域名**：`https://ad.alfq.org/`，Android 客户端禁止使用。

## 快速入口

- 登录/注册：`AuthService`
- 当前用户：`UserService`
- Feed：`FeedService`
- 交易员主页：`TraderService`
- 信号：`SignalsService`
- 告警：`AlertService`
- 通知：`NotificationService` + `/sse/notifications`
- MT 账户绑定：`MT4Service` / `MT5Service`（详见 `08-MT账户绑定-客户端实现指南.md`）
- 系统健康检查：`SystemService/Healthz`
