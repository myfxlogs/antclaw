## 一、P0 — 核心社交闭环（本周）

### 1.1 DeletePost RPC + 级联删除

**Proto 扩展** — `proto/antclaw/v1/alfq_feed.proto`:

```protobuf
// FeedService 新增
rpc DeletePost(DeletePostRequest) returns (DeletePostResponse);

message DeletePostRequest { string post_id = 1; }
message DeletePostResponse { bool success = 1; }
```

**Handler** — `backend/internal/adapter/rpc/alfq_feed_handler.go`:

```go
func (h *FeedHandler) DeletePost(ctx context.Context, req *connect.Request[alfqv1.DeletePostRequest]) (*connect.Response[alfqv1.DeletePostResponse], error) {
    userID := userIDFromHTTP(ctx, req)
    if userID == "" {
        return nil, connect.NewError(connect.CodeUnauthenticated, nil)
    }
    postID := req.Msg.PostId
    // 验证帖子所有权
    var authorID string
    err := h.pool.QueryRow(ctx, "SELECT author_id FROM alfq_posts WHERE id=$1", postID).Scan(&authorID)
    if err != nil {
        return nil, connect.NewError(connect.CodeNotFound, err)
    }
    if authorID != userID {
        return nil, connect.NewError(connect.CodePermissionDenied, errors.New("not your post"))
    }
    // 级联删除：评论/赞/转发记录由 DB CASCADE 自动处理
    _, err = h.pool.Exec(ctx, "DELETE FROM alfq_posts WHERE id=$1", postID)
    if err != nil {
        return nil, connect.NewError(connect.CodeInternal, err)
    }
    return connect.NewResponse(&alfqv1.DeletePostResponse{Success: true}), nil
}
```

**注意**: `alfq_comments` 和 `alfq_likes` 的 FK 已设 `ON DELETE CASCADE`，无需额外代码。

### 1.2 GetFollowingFeed — 关注者时间线

**Proto 扩展** — `proto/antclaw/v1/alfq_feed.proto`:

```protobuf
rpc GetFollowingFeed(GetFollowingFeedRequest) returns (FeedResponse);

message GetFollowingFeedRequest {
  string cursor = 1;       // created_at 游标 (ISO 8601)
  int32 page_size = 2;     // 默认 20
}
```

**Handler**:

```go
func (h *FeedHandler) GetFollowingFeed(ctx context.Context, req *connect.Request[alfqv1.GetFollowingFeedRequest]) (*connect.Response[alfqv1.FeedResponse], error) {
    userID := userIDFromHTTP(ctx, req)
    if userID == "" {
        return nil, connect.NewError(connect.CodeUnauthenticated, nil)
    }
    r := req.Msg
    // 查询关注的用户帖子
    cursorCond := ""
    args := []interface{}{userID}
    if r.Cursor != "" {
        cursorCond = " AND p.created_at < $2"
        args = append(args, r.Cursor)
    }
    pageSize := clampPage(r.PageSize)
    args = append(args, pageSize+1)

    rows, err := h.pool.Query(ctx, fmt.Sprintf(`
        SELECT p.id, p.author_id, p.author_name, p.content, p.post_type,
               p.signal_pair, p.signal_direction, p.signal_confidence, p.visibility,
               (SELECT COUNT(*) FROM alfq_likes WHERE post_id=p.id) as like_count,
               (SELECT COUNT(*) FROM alfq_comments WHERE post_id=p.id) as comment_count,
               p.created_at
        FROM alfq_posts p
        JOIN alfq_follows f ON f.following_id = p.author_id
        WHERE f.follower_id = $1 AND p.visibility IN ('public','followers')%s
        ORDER BY p.created_at DESC LIMIT $%d
    `, cursorCond, len(args)), args...)
    // ... scan + return (复用 GetFeed 的 scan 逻辑)
}
```

**游标**: 沿用 `created_at` 比较（不要犯 UUID 游标的错误），`next_cursor` 返回最后一行的 `created_at` 的 ISO 8601 字符串。

```go
// 在 GetPost 返回的 Post 中填充 comments
func loadComments(ctx context.Context, pool *pgxpool.Pool, postID string) ([]*alfqv1.Comment, error) {
    rows, _ := pool.Query(ctx, `
        WITH RECURSIVE comment_tree AS (
            SELECT id, post_id, parent_id, author_id, author_name, content, created_at, 0 as depth
            FROM alfq_comments WHERE post_id=$1 AND parent_id IS NULL
            UNION ALL
            SELECT c.id, c.post_id, c.parent_id, c.author_id, c.author_name, c.content, c.created_at, ct.depth+1
            FROM alfq_comments c JOIN comment_tree ct ON c.parent_id = ct.id
        ) SELECT * FROM comment_tree ORDER BY depth, created_at ASC
    `, postID)
    // 构建树形结构返回
}
```

**Handler 逻辑**:

```go
func (h *FeedHandler) CreatePost(ctx context.Context, req *connect.Request[alfqv1.CreatePostRequest]) (*connect.Response[alfqv1.Post], error) {
    // 1. 创建帖子（现有逻辑）
    // 2. 处理媒体上传
    for _, data := range req.Msg.MediaData {
        url, w, h, err := uploadToMinIO(ctx, data, userID, postID)
        // 3. 写入 alfq_post_media
        h.pool.Exec(ctx, "INSERT INTO alfq_post_media (post_id, url, width, height, size_bytes) VALUES ($1,$2,$3,$4,$5)",
            postID, url, w, h, len(data))
    }
    // 4. 返回帖子时填充 media_urls
}
```

**存储**: 复用已有 MinIO (`deploy/docker-compose.yaml` 中已配置，bucket: `antclaw-media`)。
