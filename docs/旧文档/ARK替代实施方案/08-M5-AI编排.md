## 2. T1 AI Provider 接口

### 2.1 接口定义

**文件**：`backend/internal/service/ai/provider.go`

```go
package ai

import "context"

type Provider interface {
    Name() string
    Chat(ctx context.Context, req ChatRequest) (*ChatResponse, error)
    SupportsStreaming() bool
}

type ChatRequest struct {
    Model       string
    Messages    []ChatMessage
    Temperature float64
    MaxTokens   int
    System      string
}

type ChatMessage struct {
    Role    string  // system | user | assistant
    Content string
}

type ChatResponse struct {
    Content      string
    UsedModel    string
    InputTokens  int
    OutputTokens int
    Latency      time.Duration
}
```

## 3. T2 Cached Interpreter

### 3.1 文件

`backend/internal/service/ai/interpreter.go`

### 3.2 接口

```go
type Interpreter struct {
    provider Provider
    cache    InterpretationCache
    rate     *RateLimiter
}

func (i *Interpreter) Interpret(ctx context.Context, subject, subjectID, locale string) (string, bool, error) {
    key := cacheKey(subject, subjectID, locale)
    if v, ok := i.cache.Get(ctx, key); ok {
        return v, true, nil
    }
    if !i.rate.Allow(ctx, "interpret") {
        return fallbackTemplate(subject, subjectID, locale), false, nil
    }
    prompt := buildInterpretPrompt(subject, subjectID, locale)
    resp, err := i.provider.Chat(ctx, ChatRequest{Messages: []ChatMessage{{Role: "user", Content: prompt}}})
    if err != nil {
        return fallbackTemplate(subject, subjectID, locale), false, nil
    }
    _ = i.cache.Set(ctx, key, resp.Content, 1*time.Hour)
    return resp.Content, false, nil
}
```

### 3.3 缓存层

```go
type InterpretationCache interface {
    Get(ctx context.Context, key string) (string, bool)
    Set(ctx context.Context, key string, val string, ttl time.Duration) error
    Invalidate(ctx context.Context, prefix string) error
}
```

实现：Redis（key=`ai:interpret:<sha256(subject:subjectID:locale)>`）。

### 3.4 失效策略

- 数据更新时（如新 COT 发布、新 FRED 同步），通过 Pub/Sub 通知 Interpreter 失效相关 prefix
- 例：`ai:interpret:cot:*` 在 COT 同步完成后批量删除

## 4. T3 Context Builder

### 4.1 文件

`backend/internal/service/ai/context_builder.go`

### 4.2 行为

输入 `(asset, scope)`，输出一段结构化的上下文文本，供后续 Chat 注入。

```go
func BuildContext(ctx context.Context, asset, scope string) (string, error) {
    var sections []string

    // 1. 价格快照
    p, _ := priceSvc.GetSnapshot(ctx, asset)
    sections = append(sections, fmt.Sprintf("Price: %.2f, 24h: %.2f%%", p.Last, p.Change24h))

    // 2. 宏观（macro scope）
    if scope == "macro" {
        m, _ := macroSvc.GetLatestRegime(ctx)
        sections = append(sections, fmt.Sprintf("Regime: %s", m.Regime))
    }

    // 3. 期权（crypto/equities）
    if scope == "crypto" || scope == "equities" {
        gex, _ := optionsSvc.GetGEX(ctx, asset)
        sections = append(sections, fmt.Sprintf("GEX total: %.2f, zero-gamma: %.2f", gex.TotalGEX, gex.ZeroGamma))
    }

    // 4. 链上（crypto）
    if scope == "crypto" {
        oc, _ := onchainSvc.GetAnalysis(ctx, asset)
        sections = append(sections, fmt.Sprintf("Onchain regime: %s (%.2f)", oc.Regime, oc.Confidence))
    }

    return strings.Join(sections, "\n"), nil
}
```

### 4.3 缓存

5 分钟 Redis 缓存，避免对热门 asset 重复构建。

## 5. T4 Chat Service（块式对话）

### 5.1 文件

`backend/internal/service/ai/chat.go`

### 5.2 行为

ARK 的 chat_service 通过"块（blocks）"组织消息：

- `system_block`：固定的指令（系统角色、风格、安全护栏）
- `context_block`：来自 ContextBuilder
- `history_block`：用户历史对话（最多 N 轮）
- `user_block`：当前问题

```go
type ChatBlocks struct {
    SystemBlock  string
    ContextBlock string
    History      []ChatMessage
    UserMessage  string
}

func (s *Chat) RespondBlocks(ctx context.Context, sessionID string, blocks ChatBlocks) (*ChatResponse, error) {
    msgs := []ChatMessage{
        {Role: "system", Content: blocks.SystemBlock},
        {Role: "system", Content: blocks.ContextBlock},
    }
    msgs = append(msgs, blocks.History...)
    msgs = append(msgs, ChatMessage{Role: "user", Content: blocks.UserMessage})

    if !s.rate.Allow(ctx, "chat:"+sessionID) {
        return &ChatResponse{Content: fallbackChatTemplate(blocks), UsedModel: "fallback"}, nil
    }

    resp, err := s.provider.Chat(ctx, ChatRequest{Messages: msgs})
    if err != nil {
        return &ChatResponse{Content: fallbackChatTemplate(blocks), UsedModel: "fallback"}, nil
    }

    s.history.Append(ctx, sessionID, blocks.UserMessage, resp.Content)
    return resp, nil
}
```

### 5.3 历史持久化

```sql
CREATE TABLE ai_chat_history (
  session_id TEXT NOT NULL,
  seq INT NOT NULL,
  role TEXT NOT NULL,
  content TEXT NOT NULL,
  created_at TIMESTAMPTZ NOT NULL DEFAULT now(),
  PRIMARY KEY (session_id, seq)
);
```

### 5.4 SSE 流式（可选）

若 Provider 支持 streaming，则：

- Connect Unary 返回 `session_id` 与 `stream_id`
- 客户端订阅 `/sse/ai_chat?stream_id=...`
- 后端将 token 流逐块推送

> M5 阶段 SSE 流式作为可选实现；先确保非流式 Unary 路径稳定。

## 6. T5 AI 限流与降级

### 6.1 文件

`backend/internal/service/ai/ratelimit.go`

### 6.2 限流策略

- **全局 RPM**：每个 Provider 默认 15 RPM，可在 `system_ai_configs.max_rpm` 覆盖
- **每用户 RPM**：默认 5 RPM，超出返回 `errs.RateLimited` 但前端显示 "请稍后重试"
- **每会话并发**：1（避免同一用户连点引发并发对话）
- **失败降级**：连续失败 3 次后切到 `fallback_template`，60s 后恢复

### 6.3 降级模板


模板使用 Go `text/template`，输入 ContextBuilder 输出，输出"机器可读但不需 AI"的解读文本。

## 7. T6 BYOK 与系统密钥优先级

### 7.1 优先级规则

```
1. 用户 BYOK 密钥（user_byok 表，per-user）→ 优先
2. 系统默认密钥（system_ai_configs.api_key）→ 次选
3. 任何 Provider 都无 key → 返回 fallback_template
```

### 7.2 实现

`service/byok/resolver.go`：

```go
func (r *Resolver) ResolveAIKey(ctx context.Context, userID, provider string) (string, string) {
    // returns (apiKey, source) where source ∈ {byok, system, none}
    if k := r.getUserKey(ctx, userID, provider); k != "" {
        return k, "byok"
    }
    if k := r.getSystemKey(ctx, provider); k != "" {
        return k, "system"
    }
    return "", "none"
}
```

### 7.3 计费/计数

每次 AI 调用记入 `ai_usage`：

```sql
CREATE TABLE ai_usage (
  id UUID PRIMARY KEY,
  user_id TEXT,
  provider TEXT,
  model TEXT,
  source TEXT,             -- byok | system
  input_tokens INT,
  output_tokens INT,
  latency_ms INT,
  status TEXT,             -- ok | fallback | error
  created_at TIMESTAMPTZ NOT NULL DEFAULT now()
);
```
