## 1. GetBriefing — 每日宏观简报

### 1.1 输入
```proto
message GetBriefingRequest { string category = 1; }   // fx/crypto/macro/all
```

### 1.2 算法

**步骤 1：聚合数据**（全部用真实表）
```
sections = []

# 1. Macro 状态
overlay = RegimeProvider.GetCurrent("DXY","1d")        // 用 DXY 代表全市场风险
sections.append({title:"宏观状态", content: macroNarrative(overlay), priority:"high"})

# 2. COT 极端
extremes = COTProvider.GetCurrencyExtremes(threshold=0.85)
if extremes: sections.append({title:"COT 极端", content: cotNarrative(extremes), priority:"high"})

# 3. 资金流背离
flows = FlowProvider.GetTopDivergent(now-7d, limit=3)
if flows: sections.append({title:"资金流背离", content: flowNarrative(flows), priority:"medium"})

# 4. 因子排名变化
top_movers = compareSnapshots(today, yesterday, n=3)
if top_movers: sections.append({title:"因子排名变动", content: factorMoveNarrative(top_movers), priority:"medium"})

# 5. 即将到来事件（Calendar）
events = CalendarProvider.GetUpcoming(now, now+24h, importance="high")
if events: sections.append({title:"今日重要事件", content: eventsNarrative(events), priority:"high"})

# 按 category 过滤
sections = filterByCategory(sections, category)
```

**步骤 2：AI 润色（可选）**
- 若 system_ai_configs 中有 `primary_for=summarizer` 的 provider：把 sections 拼接成 prompt，让 AI 输出 200-400 字总览，作为 sections[0]（title="AI 综述"）。
- 失败则返回原始 sections，加 missing="ai_summary"。

### 1.3 narrative 函数模板

文件：`backend/internal/service/signals/narrative.go`

```go
func macroNarrative(r *RegimeSnapshot) string {
    return fmt.Sprintf(
        "当前宏观状态：%s（综合得分 %.2f）。HMM 模型置信度 %.0f%%，波动率制度为 %s（vol_ratio=%.2f）。趋势强度 %s（ADX=%.0f）。",
        r.UnifiedLabel, r.UnifiedScore, r.HMMConfidence*100,
        r.GARCHRegime, r.VolRatio, r.ADXStrength, r.ADXValue,
    )
}

func cotNarrative(items []COTAnalysis) string {
    var sb strings.Builder
    for _, c := range items {
        sb.WriteString(fmt.Sprintf("• %s：COT index %.0f（%s），周变化 %+d 张合约。\n",
            c.ContractCode, c.COTIndex, c.Direction, c.WoWChange))
    }
    return sb.String()
}

// flowNarrative / factorMoveNarrative / eventsNarrative 类似
```

## 2. GetOutlook — 每周宏观展望

### 2.1 输入
```proto
message GetOutlookRequest { string pair = 1; string horizon = 2; } // short/medium/long
```

### 2.2 算法

```
horizon_days = {"short":7, "medium":30, "long":90}[horizon]

# 1. 历史相同状态下未来 N 天表现
similar_periods = findHistoricalAnalog(
    symbol, current_regime, current_factor_composite, lookback=10y
)
if len(similar_periods) >= 5:
    avg_return = mean(forward_return(p, horizon_days) for p in similar_periods)
    win_rate   = sum(forward_return > 0 for p in similar_periods) / len(similar_periods)
else:
    avg_return = nil  # 数据不足

# 2. 基于状态转换矩阵的展望
transition = transitionMatrix.GetForward(symbol, horizon_days)

# 3. 综合方向
score = 0.4 * sign(avg_return) * win_rate
      + 0.4 * (transition.bull_prob - transition.bear_prob)
      + 0.2 * current_unified_score

outlook = "bullish" if score > 0.2 else "bearish" if score < -0.2 else "neutral"
confidence = sigmoid(abs(score) * 4)
```

`findHistoricalAnalog`：
```sql
SELECT time FROM regime_overlay_history
WHERE symbol = $1
  AND unified_label = $2
  AND abs(unified_score - $3) < 0.15
  AND time < now() - INTERVAL '$4 days'
ORDER BY time DESC
LIMIT 50
```

`forward_return(p, days)`：从 `price_daily` 取 `(p.time, p.time + days)` 的 close 比值。

### 2.3 AI 文本（可选）
若 `with_ai_summary=true`，对每个 outlook 调用 LLM 生成 50-80 字解释，附在 `OutlookData.outlook` 之后。

### 2.4 输出
```go
&GetOutlookResponse{
    Outlooks: []*OutlookData{
        {Pair: pair, Outlook: "bullish", Confidence: 0.62, Horizon: "short"},
        {Pair: pair, Outlook: "neutral", Confidence: 0.45, Horizon: "medium"},
        ...
    },
}
```

## 3. AI 调用封装

复用 `internal/service/ai`（已存在）。具体：

```go
type Summarizer interface {
    Summarize(ctx context.Context, prompt string, maxTokens int) (string, error)
}

func NewSummarizerFromSystemConfigs(ctx context.Context, sysai *systemai.Service) (Summarizer, error) {
    cfg := sysai.GetPrimaryFor(ctx, "summarizer")
    if cfg == nil { return nil, ErrNoSummarizerConfigured }
    return ai.NewProvider(cfg), nil
}
```

错误处理：
- timeout 5s
- 失败时不抛错给 caller，**记录指标**：`ai_summary_failed_total{reason}` Prometheus counter
