## 3. apiclient.Source 关键修复

发现并修复一个会导致下游解码失败的 Bug：

- 旧实现：`Do()` 内 `ctx, cancel := context.WithTimeout(ctx, s.timeout); defer cancel()`，`defer cancel()` 在函数返回时立即触发，下游对 `resp.Body` 的延迟读取会得到 `context canceled` 错误。
- 新实现：废弃 `WithTimeout`，改由 `http.Client{Timeout: t}` 持有超时（覆盖整个请求生命周期，含 body 读取）。
- 影响：DefiLlama、SEC EDGAR 等大响应体场景从“unavailable: context canceled”修复为正常返回。

## 7. 风险与回滚

- Deribit / DefiLlama / SEC EDGAR / World Bank / US Treasury：均为公开端点，无 Key 依赖；如上游临时不可用，handler 返回 503 由前端做缓存兜底；可通过将对应 handler 降级为 Unimplemented 快速回滚。
- CBOE：CSV 端点常变动；handler 已实现 fetch 失败返回空响应，避免 500 阻塞。
- 限流/断路器：apiclient.Source 已支持，但默认未启用；启用方式为在创建时传入 `RedisClient + RateLimitPerMin + BreakerFailures`。
