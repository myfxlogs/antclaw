### 6) 管理面全部 Connect-RPC 收口

- **采集汇总/预览**：`proto/antclaw/v1/admin_data.proto`、`data_corpus.go`、`admin_data_connect_handler.go`；前端 `getDataSummary` / `getDataPreview`；已移除 `/admin/data/*` REST 与 nginx 对应反代。
