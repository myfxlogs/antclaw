> 范围：协议合规改造、apiclient.Source 中间件、薄客户端落地（CoinGecko/CFTC/Yahoo）、Crypto 信封 RPC、SystemService 健康端点、协议 lint。

## 一、协议合规

  - 注册 SystemService（Healthz/Readyz/Info）
  - Crypto envelope 切换为 `CryptoService.PostEnvelope`
- 协议 lint：
  - `backend/scripts/lint-protocol.sh` 通过：`OK: 后端协议合规`
- 前端：
  - 无 `fetch/axios/WebSocket/setInterval` 业务残留（grep 验证）

## 二、apiclient.Source 中间件

- `backend/internal/infra/apiclient/source.go`
- 接口：`Vendor()` / `Do()` / `Healthz()`
- 默认实现：超时 + 计数 + 健康快照
- 可选 Redis：限流（每分钟）+ 断路器（失败阈值/恢复窗口）
- 不传 Redis 时仅启用基础语义，向后兼容

## 三、薄客户端与采集改造

| Vendor | 路径 | 用途 |
|---|---|---|
| CoinGecko | `internal/infra/apiclient/coingecko/` | 链上市值/量能曲线 |
| CFTC v1 | `internal/infra/apiclient/cftc_client.go`（已有） | COT legacy 报表，优先使用 |
| Yahoo | `internal/infra/apiclient/yahoo/` | 价格 OHLC（替换 collector 中内联调用）|

- `cmd/antclaw-worker/collector_onchain.go`：使用 CoinGecko 薄客户端，UTC 日粒度截断
- `cmd/antclaw-worker/collector_cot.go`：先调 CFTC v1 legacy，失败回退 Socrata，并新增 `saveLegacyReports` 落库
- `cmd/antclaw-worker/collector_price.go`：`fetchYahoo` 改为通过 apiclient.Source + yahoo 薄客户端

## 四、Crypto 信封 RPC

- 新增 `proto/antclaw/v1/crypto.proto::PostEnvelope`
- 实现 `internal/adapter/rpc/crypto_connect_handler.go::PostEnvelope`：
  - HMAC（timestamp/nonce/body）+ Redis 抗重放
  - RSA-OAEP + AES-GCM 解密
  - 返回明文 base64 占位（后续按 `target_path` 进程内路由）
- 前端 `crypto.ts::sendSecurePut` 改为 connect-web 调用，签名对象切换为 base64 字符串

## 五、SystemService

- 新增 `proto/antclaw/v1/system.proto`：`Healthz/Readyz/Info`
- 实现 `internal/adapter/rpc/system_handler.go`
- 前端 `lib/api.ts::getSystemHealth` 调用 SystemService.Healthz
