# AlfQ Android · 构建指南

> 在目标机器（Ubuntu 24.04）上构建。

## 方式一：Git（推荐）

```bash
git clone git@github.com:myfxlogs/antclaw.git
cd antclaw
```

已有完整代码在 `frontend/android/`。

## 方式二：Tarball

将 `/tmp/alfq-android.tar.gz`（113KB）传到目标机器：

```bash
scp /tmp/alfq-android.tar.gz user@target:/path/
# 在目标机器上：
tar -xzf alfq-android.tar.gz
```

## 目标机器环境

```bash
# 1. 安装 Java 17
sudo apt-get install -y openjdk-17-jdk-headless

# 2. 安装 Android SDK 命令行工具
mkdir -p ~/android-sdk/cmdline-tools && cd /tmp
curl -sLO https://dl.google.com/android/repository/commandlinetools-linux-11076708_latest.zip
unzip -qo commandlinetools-*.zip -d ~/android-sdk/cmdline-tools
mv ~/android-sdk/cmdline-tools/cmdline-tools ~/android-sdk/cmdline-tools/latest

# 3. 安装 SDK 组件
export ANDROID_HOME=~/android-sdk
export PATH=$ANDROID_HOME/cmdline-tools/latest/bin:$PATH
yes | sdkmanager --licenses
sdkmanager "platform-tools" "platforms;android-35" "build-tools;35.0.0"

# 4. 生成 Kotlin proto 桩（如 tarball 未包含 gen/kotlin/）
cd antclaw/frontend/android
# 安装 protoc（参考 buf.gen.yaml 注释）
# 或直接使用 gen/kotlin/ 中已生成的桩
```

## 使用 Android Studio（最简单）

1. 打开 Android Studio
2. File → Open → 选择 `frontend/android/`
3. 等待 Gradle 同步完成
4. Run → Run 'app'

Android Studio 会自动处理 SDK 下载、Gradle 同步、proto 生成。Kotlin 源码已在 Ubuntu 上验证编译零错误。
