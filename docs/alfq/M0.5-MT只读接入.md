## 数据流

```
Me → 交易账号 [+添加]
  │
  ├─→ MT5Service.AddAccount (server/account/password → 连接验证)
  │     └→ 成功：存储账号信息
  │
  ├─→ MT5Service.GetAccountInfo
  │     └→ 余额 / 净值 / 保证金
  │
  ├─→ MT5Service.GetPositions
  │     └→ 当前持仓列表
  │
  └─→ MT5Service.GetHistory (≥30 笔 → 🟢 亮标)
        └→ 自动计算：胜率 / 盈亏比 / 夏普
```

## 共享上下文

> 以下通用约定在索引文档中定义，此处仅摘要。开发时参照索引文档获取完整信息。

| 项目 | 约定 |
|---|---|
| RPC 端点 | `POST /antclaw.v1.<Service>/<Method>`，`Content-Type: application/json` |
| 认证 | `Authorization: Bearer <JWT>`，token 过期跳转登录页 |
| SSE 连接 | `GET /sse/<channel>` + `Authorization: Bearer <JWT>`，消息格式 `event: <type>
data: <json>` |
| 重连 | 指数退避 1s→2s→4s→max 30s |
| 分页 | 列表类 RPC 统一 `cursor` 分页，每页 20 条 |
| 缓存 | Room 本地缓存，新数据覆盖，无网络永久保留 |
| 错误 | `CodeUnauthenticated` → 登录页；`CodeUnavailable` → 缓存+提示；其余 → toast message |
| 版本 | 所有新 Service 注册到 `proto/antclaw/v1/`，改 proto 后执行 `buf generate` |
